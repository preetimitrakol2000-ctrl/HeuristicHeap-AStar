# HeuristicHeap-AStar

A custom performance layer written in C to compute optimal route selections from scratch. By using a manually managed Min-Heap structure, this tool provides $O(\log N)$ extraction speeds for cost nodes, reflecting standard architectures used in AI game mechanics and robotic navigation tasks.

## ⚡ Data Structure Complexities
* **Insertion Time:** $O(\log N)$
* **Extract Minimum Element:** $O(\log N)$
* **Space Allocation:** Flat contiguous structural arrays.
